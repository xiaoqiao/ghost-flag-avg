# 幽灵旗 · 那多手记 AVG

改编自那多《幽灵旗》（那多灵异手记系列）的网页文字冒险游戏：视觉小说 + 推理 + 小游戏，多结局。

**在线游玩：** https://xiaoqiao.github.io/ghost-flag-avg/

> 2004 年，记者那多受命报道闸北几幢即将拆除的“三层楼”。一张 1937 年日军轰炸后的老照片上，四周一片废墟，唯独四幢楼毫发无损——据说是因为楼顶飘出过一面旗。

## 怎么玩
- 电脑：用 Chrome / Edge / Safari 打开上面的链接。点击或空格推进，按住 Ctrl 快进，滚轮上翻回看，N 打开工作手册，右键隐藏对话框。
- 手机 / 平板：始终以横屏显示——竖着拿时画面会自动转过来，把手机横过来玩即可（开着方向锁定也行）；右侧“☰”按钮打开菜单；浏览器里选择“添加到主屏幕”，就能像 App 一样全屏打开。iPhone 开着静音开关时没有声音。
- 共 9 章 + 尾声，12 处推理，9 个小游戏，10 个结局（1 真 · 1 普通 · 8 坏）。走进死路可以“回到抉择前”；小游戏太难可以在设置里打开“简单模式”。
- 云存档：点标题画面右上角的「☁ 登录 / 注册」注册一个账号，进度会自动同步到云端，在另一台设备登录同一账号即可接着玩；不登录也能玩，存档保存在你自己的浏览器里。
- 存档保存在你自己的浏览器里，每个人、每台设备各自独立。想在另一台设备接着玩：「读取存档 → 导出存档码」，把那串文字发到另一台设备，在那边「导入存档码」即可（也可以下载成文件）。

## 本地运行
下载本仓库，双击 `index.html` 即可，无需联网、无需安装（云存档需要联网）。

`server/` 是云存档后端：Python 标准库 + SQLite 的极简服务（`ghostflag_api.py`），附 systemd 与 Apache 反向代理配置。密码只存 scrypt 加盐哈希，存档只含游戏进度。
